# Cybersecurity Awareness & Threat Intelligence Dashboard

A responsive Streamlit dashboard for monitoring cyber threats, awareness readiness, and operational security posture.

## Features

- Threat incident trend tracking
- Severity and risk scoring overview
- Business-unit risk heatmap
- Awareness training readiness dashboards
- Executive action prioritization cards
- Filter controls for date, region, threat type, and risk threshold

## Run locally

```bash
python -m streamlit run app.py --server.headless true --server.port 8555
```

## Dependencies

```bash
pip install -r requirements.txt
```
